# 恋のことのは

声に出して英単語を発音すると、ストーリーが進む英語学習ゲームです。
ブラウザだけで動きます。インストール不要。

**▶ [プレイする](https://goldfish0824-web.github.io/koi-no-kotonoha/)**

## 遊び方

画面に出た日本語の意味に合う英単語を、声に出して発音します。
正しく発音できるとストーリーが進み、ひとつの恋が少しずつ実っていきます。

- 全6章 × 3つの物語
- 収録 600 語
- 言えなかった単語は自動で記録され、あとから練習できます

## 動作環境

| 端末 | 推奨ブラウザ |
|---|---|
| iPhone | Safari |
| Android | Chrome |
| PC | Chrome / Edge |

**LINEなどのアプリ内ブラウザでは音声入力が使えません。**
QRコードから開いた場合は、メニューから「Safariで開く」を選んでください。

うまく動かないときは、タイトル画面の「マイクの確認」をお試しください。
iPhoneでは「設定 → 一般 → キーボード → 音声入力」がオンである必要があります。
